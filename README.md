# WARDOGS GPS for Windows

The first public download is in preparation. When a build is available, its release page will list the Windows ZIP, checksum, installation instructions and known map coverage. [Windows releases](https://github.com/jimmicha/wardogs-gps-releases/releases)

## Support

For a bug or setup question, include the app version, map, edition and steps that led to the problem. Support tickets and attachments on GitHub are public. Keep license files, receipts, names and email addresses private. [Get technical support](https://github.com/jimmicha/wardogs-gps-releases/issues/new/choose)

For a purchase, missing license or refund request, open the original PayPal transaction and use the seller contact shown in its details. Include the transaction ID in that private correspondence.

## Road contributions

Private beta testers can export a game-map road from **Road mapping** and submit it for publisher review. The form explains which coordinates become public. Reviewed road packs can be included as attachments on a release. Import a pack using **Road mapping → Import road pack…**, inspect the proposals on the map, then choose which roads to use locally. [Submit a road](https://github.com/jimmicha/wardogs-gps-releases/issues/new?template=road.yml)

WARDOGS GPS is an unofficial companion. WARDOGS and its game assets belong to their respective rights holders.
